# Python Day 80 - Largest and Smallest

This program takes multiple numbers from the user and finds the largest and smallest number using `max()` and `min()`.

## Example

Input:
25
10
45
5
30

Output:
Largest: 45
Smallest: 5

## Concepts Used

- Lists
- for loop
- input()
- append()
- max()
- min()
- User Input
